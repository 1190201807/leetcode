LeetCode 72 中等编辑距离 — 图解动态规划

把 word1 变成 word2 的最少操作数（插入 / 删除 / 替换各算一步）——经典二维 DP，也是"双字符串 DP"的原型题。

一、题目回顾

  • horse → ros：3 步（替换 h→r，删 r…，删 e），见下方动画逐步验证
  • intention → execution：5 步

难点：操作可以发生在任意位置，暴力枚举所有编辑序列是指数级；必须找到"规模更小的同款问题"。

二、状态定义：只看"前缀"，规模立刻缩小

核心洞察：不要纠结"整串怎么变"，只问——把 word1 的前 i 个字符变成 word2 的前 j 个字符，最少几步？ 这就是状态 dp[i][j]。一旦把问题钉在"前缀对前缀"上，任何一步操作都只牵动 i 或 j 的边缘一格，转移方程水到渠成。 答案 = dp[m][n]（m、n 为两串长度）。

边界（表格的第 0 行、第 0 列）

  • dp[0][j] = j：空串变成 word2 的前 j 个字符，只能连插 j 次
  • dp[i][0] = i：word1 的前 i 个字符变成空串，只能连删 i 次

三、状态转移：盯住两个串的"最后一个字符"

比较 word1[i-1] 与 word2[j-1]（前缀的末尾字符）：

情形 A：两字符相等 —— 白嫖一步

dp[i][j] = dp[i-1][j-1]。末尾已经一样，无需任何操作，问题直接缩成"前 i-1 → 前 j-1"。
注意是照抄而不是 +1，相等是免费的。

情形 B：两字符不同 —— 三选一，各付 1 步

选择操作为什么对应这个子问题
dp[i][j-1] + 1 插入 在 word1 末尾插入 word2[j-1]，末尾对齐 → 剩下 word1[:i] → word2[:j-1]
dp[i-1][j] + 1 删除 删掉 word1[i-1]，末尾消掉 → 剩下 word1[:i-1] → word2[:j]
dp[i-1][j-1] + 1 替换 把 word1[i-1] 改成 word2[j-1]，末尾同时消掉 → 剩下 word1[:i-1] → word2[:j-1]

dp[i][j] = min(三者)。三种操作"各管各的后缀消去方式"，恰好完备、互不重叠。

四、Python 实现

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[i][j]：word1 前 i 个字符 → word2 前 j 个字符的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 边界：空串 ↔ 前缀
        for j in range(n + 1):
            dp[0][j] = j          # 连插 j 次
        for i in range(m + 1):
            dp[i][0] = i          # 连删 i 次

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]          # 末尾相等，免费
                else:
                    dp[i][j] = min(
                        dp[i - 1][j - 1] + 1,            # 替换
                        dp[i - 1][j] + 1,                # 删除
                        dp[i][j - 1] + 1,                # 插入
                    )
        return dp[m][n]

六、复杂度分析

时间
O(m·n)

每个 (i, j) 格子计算一次，每次 O(1)。

空间
O(m·n)

整张表；观察到 dp[i][j] 只依赖上一行与当前行左格，可用滚动数组压缩到 O(n)（从右往左更新一维数组）。

优于暴力
指数 → 多项式

暴力枚举编辑序列是指数级；DP 把重复子问题（同一对前缀被反复求解）缓存下来。

七、常见疑问与拓展

  • Q：为什么"相等"时不用再考虑插入/删除？
    数学上可证相等时 dp[i-1][j-1] ≤ min(dp[i-1][j], dp[i][j-1], 其他)+1 恒成立，照抄左上一定不亏；直觉上，末尾白得一个匹配没有任何理由放弃它。
  • Q：怎么还原出具体做了哪些操作？
    从 dp[m][n] 往回走：值等于左上 → 相等或替换；等于上+1 → 删除；等于左+1 → 插入。动画最后一步的绿色路径就是这条回溯线。
  • Q：这题的通用变体？
    把三种操作的代价改成不同权重（替换 2、插入删除 1 等），转移方程里把对应 +1 改成 +cost 即可；只允许删除时退化为"最长公共子序列"（LC 1143）。
  • 相关题目：LC 1143 最长公共子序列（同款骨架）、LC 583 两个字符串的删除操作、LC 712 两个字符串的最小 ASCII 删除和、LC 44 通配符匹配（双字符串 DP）。

双字符串 DP 模板：dp[i][j] 定前缀 → 末尾相等抄左上，否则左上/上/左三选一。
