4. 寻找两个正序数组的中位数 O(log(m+n)) · 二分查找

给定两个升序数组 nums1 与 nums2（长度分别为 m、n），返回合并后有序数组的 中位数，要求复杂度 O(log(m+n))。

② 直觉：能否用二分

"找中位数"本质上是按位置找第 k 小的数。合并后中间位置之前，恰好有 — 个元素。先想一个更简单的问题：

子问题
在两个数组里找第 k 小的数（k 从 1 开始计数）——记作 getKth(nums1, nums2, k)。

每次比较两个数组"大致第 k/2 位"的数，较小的那一位及其前面的所有元素，都不可能成为第 k 小，可以整段丢弃。

为什么敢整段丢弃？（正确性 · 计数论证）
设 nums1 的第 k/2 个候选 a[k/2−1] ≤ nums2 的第 k/2 个候选 b[k/2−1]（如演示第一轮的 10 ≤ 17）。数一数全合并数组里有多少元素 ≤ a[k/2−1]：
① nums1 里：它自己及之前 → 最多 k/2 个；
② nums2 里：因 b[k/2−1] ≥ 它且 nums2 升序，该候选之后的元素全被排除，只有其前面可能更小 → 最多 k/2−1 个。
合计 ≤ k−1 个 → a[k/2−1] 最坏也只排第 k−1 位，它连同前面的 k/2 个元素全在第 k 位之前，扔掉绝不误伤第 k 小。
又因每次丢掉的恰是当前最小的 k/2 个（不变量），原第 k 小在剩下的人中升为第 k−k/2 小 → k −= k/2。k 减到 1 时取两数组头部较小者即为答案。

③ 简洁方案：割板法 · 四步推导

第 0 步 · 换个角度看中位数：它是一条分界线

中位数不是"某个数"，而是把所有数分成小的左半和大的右半的那条线。总长 T 时左半占 ⌈T/2⌉ 个（奇数时多 1 个）。于是：中位数 = 左半的最大值（偶数时再与右半最小求平均）。问题转化为——把最小的 ⌈T/2⌉ 个数挑进左半。

第 1 步 · 左半必然是两个数组的"前缀"

两数组各自有序，要凑"最小的若干个"只能从队头连续地拿：假如从 nums1 拿 4 个却跳过 1 去拿 3,8,9,15，左半就不是最小的那批了。收获：不用考虑"挑哪几个"，唯一自由度是每队拿几个——记作 cut1、cut2。

第 2 步 · 两个未知数坍缩成一个

左半名额是定死的：cut1 + cut2 = —。所以 cut2 = ⌈T/2⌉ − cut1——定了 cut1，刀在 nums2 的位置自动算出。整个问题只剩一个待定数 cut1 ∈ [0, m]，共 m+1 种切法。

第 3 步 · 验收标准：左半最大 ≤ 右半最小

每个数组内部天生有序（自己队里左 ≤ 右必然成立），所以只需查两条跨队不等式：L1 ≤ R2 且 L2 ≤ R1。不通过时，信号还直接指出方向：L1 > R2 → 切大了（cut1 左移）；L2 > R1 → 切小了（cut1 右移）。

第 4 步 · 信号单调 → 二分 cut1

把 cut1 从小到大扫一遍，"过小 / 过大"的信号单调变化，正是二分的适用条件。区间 [0, m] 每次砍半，O(log min(m,n)) 步锁定正确切法。下面的第④部分就是这个二分的逐步演示。

一句话串联
中位数 = 左半最大 → 左半必是每队前缀 → 自由度只剩 cut1 → 名额公式消灭 cut2 → 两条交叉不等式当验收器 → 信号单调 → 二分 cut1。
对比 getKth 法：getKth 是"一个个往外扔"，割板法是"直接一次性分配好左半名额"、直奔终态，所以代码更短、更快（O(log min(m,n))）。

切对时长这样（┃ = 刀；左侧变暗 = 划入左半；红框 = 各自左半的最大值 L1、L2）

④ 二分搜索的逐步演示

我们只对 较短数组 nums1 在 [0, m] 区间做二分。每一步具体展示完整操作：搜索区间 → 取中点 cut1 → 名额公式算出 cut2 → 刀落位（变暗 = 划入左半）→ 验收两条不等式 → 按信号收窄区间。

⑤ 完整代码 · Python

# 保证 nums1 是较短数组，便于二分
def findMedianSortedArrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    # 合并后左边应有 (m+n+1)//2 个元素
    lo, hi = 0, m

    while lo <= hi:
        cut1 = (lo + hi) // 2          # 在 nums1 中取前 cut1 个
        cut2 = (m + n + 1) // 2 - cut1   # 自动补齐到左半长度

        L1 = nums1[cut1 - 1] if cut1 > 0 else -10**20
        R1 = nums1[cut1]     if cut1 < m else  10**20
        L2 = nums2[cut2 - 1] if cut2 > 0 else -10**20
        R2 = nums2[cut2]     if cut2 < n else  10**20

        # 左侧最大值 vs 右侧最小值 —— 交叉比较
        if L1 <= R2 and L2 <= R1:     # 分割正确
            if (m + n) % 2 == 1:
                return max(L1, L2)                  # 奇数：左侧最大
            return (max(L1, L2) + min(R1, R2)) / 2.0 # 偶数：平均
        elif L1 > R2:      # nums1 左太多 → 左移 cut1
            hi = cut1 - 1
        else:              # L2 > R1：nums1 右太小 → 右移 cut1
            lo = cut1 + 1
