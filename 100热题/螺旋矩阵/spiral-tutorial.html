①核心模型：把矩阵当成洋葱

螺旋遍历不是一格一格想，而是一圈一圈想。整个矩阵 = 一层层的环， 最外层是第 k=0 圈，往里 k=1、k=2……每走完一圈，向内收缩一格。

🔑 推论 1：圈数 = 短边的一半，向上取整

4×4 → 2 圈；3×3 → 2 圈（外圈+中心）；2×3 → 1 圈；5×5 → 3 圈。
写成 Python 就是 range((min(m, n) - 1) // 2 + 1)， 等价于 ceil(min(m,n) / 2)。记住“短边决定圈数”即可，公式现推。

②一圈的固定路线：上 → 右 → 下 → 左

每一圈永远按同一个顺序走四条边：上边向右 → 右边向下 → 下边向左 → 左边向上。 顺序固定，就不需要方向数组、不需要 while 循环，全部用 for 硬写。

关键只在“角落归谁”。四个角如果人人都走，就会重复。规则很简单：

🔑 推论 2：让头吃尾 —— 每条边的“头”让给上一条边，“尾”自己吃
  • ① 上边：第一个出发，头尾全吃（含左上角、右上角）
  • ② 右边：头（右上角）已被①吃 → 从下一行开始；尾（右下角）自己吃
  • ③ 下边：头（右下角）已被②吃 → 从右往左时先让一格；尾（左下角）自己吃
  • ④ 左边：头（左下角）已被③吃 → 让一格；尾（左上角）也让掉——它属于下一圈

于是四条边的下标范围全部由 k 推出来，不需要背，现场画一圈就能写： 设 m 行 n 列，第 k 圈的边界是 上=k、右=n-1-k、下=m-1-k、左=k。 

① 上边  行固定 = k        列: k      → n-1-k      (头尾全吃)
② 右边  列固定 = n-1-k    行: k+1    → m-1-k      (让头)
③ 下边  行固定 = m-1-k    列: n-2-k  → k   倒序   (让头)
④ 左边  列固定 = k        行: m-2-k  → k+1 倒序   (让头也让尾)

③两个特判：单行、单列的圈“没有下边 / 左边”

推论 2 隐含一个前提：这一圈真的存在四条边。但当圈内只剩 一条横线（1 行）或一条竖线（1 列）时，③④ 会沿原路倒着再走一遍，全部重复。

  • 第 14 行 if k + 1 != m - k —— 实际是在问： 上边(k 行) 和 下边(m-1-k 行) 是不是同一行？ 相等 → 这圈是一条横线，①早已走完，③必须跳过。
  • 第 18 行 if k + 1 != n - k —— 在问： 左边(k 列) 和 右边(n-1-k 列) 是不是同一列？ 相等 → 这圈是一条竖线，①+② 早已走完，④必须跳过。
🔑 推论 3：还原代码时的位置记忆

两个 if 分别挡在③和④前面：走下边之前先确认“这圈有下边”，走左边之前先确认“这圈有左边”。 注意 3×3 的中心格：此时①走的就是那 1 格，②③④全空/被跳过 —— 天然正确，不用额外处理中心点。

⑤凭空复现：五步默写法

以后写代码时，按这五步顺序默写，每一步都有明确的“为什么”：

  • 第 1 步 · 圈数：短边一半向上取整 → for k in range((min(m,n)-1)//2 + 1)
  • 第 2 步 · 上边：头尾全吃 → for i in range(k, n-k)，取 matrix[k][i]
  • 第 3 步 · 右边：让头 → for i in range(k+1, m-k)，取 matrix[i][n-1-k]
  • 第 4 步 · 下边：先写 if k+1 != m-k（有下边才走），再 for i in range(n-2-k, k-1, -1)，取 matrix[m-1-k][i]
  • 第 5 步 · 左边：先写 if k+1 != n-k（有左边才走），再 for i in range(m-2-k, k, -1)，取 matrix[i][k]
# 1. 圈数：短边一半向上取整
for k in range((min(m, n) - 1) // 2 + 1):
    # 2. 上边：头尾全吃
    for i in range(k, n - k):            res.append(matrix[k][i])
    # 3. 右边：让头吃尾
    for i in range(k + 1, m - k):        res.append(matrix[i][n - 1 - k])
    # 4. 下边：有下边才走（⭐ 单行圈跳过）
    if k + 1 != m - k:
        for i in range(n - 2 - k, k - 1, -1):  res.append(matrix[m - 1 - k][i])
    # 5. 左边：有左边才走（⭐ 单列圈跳过）
    if k + 1 != n - k:
        for i in range(m - 2 - k, k, -1):      res.append(matrix[i][k])
🧭 一句话口诀

“短边定圈数，上右下左转；让头去吃尾，单行单列砍下左。”
忘记范围时：先画一圈，标出 上=k / 右=n-1-k / 下=m-1-k / 左=k，四个范围现场推。
